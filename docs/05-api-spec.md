# 05 — REST API Specification (v1)

Base URL: `/api/v1`. All bodies are JSON. Interactive docs are generated by FastAPI at `/api/docs`
(disabled in production unless `ENABLE_DOCS=true`).

**Auth column:** `—` public · `opt` public but personalised when logged in · `C` customer ·
`O` owner (own resources only) · `A` admin · `any` any logged-in user.
Authenticated calls send `Authorization: Bearer <access_token>`.

## Common behaviour

**Error format** (every non-2xx response):
```json
{ "error": { "code": "ROOM_UNAVAILABLE", "message": "Only 0 rooms left for 13 Dec.", "details": {"date": "2026-12-13"} } }
```

| Status | Used for | Example codes |
|---|---|---|
| 400 | Business-rule violation | `INVALID_DATES`, `OCCUPANCY_EXCEEDED`, `COUPON_INVALID`, `NOT_CANCELLABLE` |
| 401 | Missing/invalid/expired token | `NOT_AUTHENTICATED`, `TOKEN_EXPIRED`, `INVALID_CREDENTIALS` |
| 403 | Logged in but wrong role / suspended | `FORBIDDEN`, `ACCOUNT_SUSPENDED`, `EMAIL_NOT_VERIFIED` |
| 404 | Not found **or not yours** (we don't reveal existence) | `NOT_FOUND` |
| 409 | Conflict with current state | `ROOM_UNAVAILABLE`, `EMAIL_TAKEN`, `HOLD_EXPIRED`, `IDEMPOTENCY_KEY_REUSED`, `ALREADY_REVIEWED` |
| 422 | Request failed schema validation | `VALIDATION_ERROR` (details list fields) |
| 429 | Rate limited | `RATE_LIMITED` (+ `Retry-After` header) |
| 500 | Unexpected — generic message + `request_id`, no stack trace | `INTERNAL_ERROR` |

**Pagination:** `?page=1&page_size=20` (max 50). Response:
`{ "items": [...], "page": 1, "page_size": 20, "total": 137, "total_pages": 7 }`

**Money:** `*_paise` integer fields. **Dates:** `YYYY-MM-DD`.

## Auth — `/auth`
| Method | Path | Auth | Body → Response | Notes / errors |
|---|---|---|---|---|
| POST | `/auth/signup` | — | `{name, email, password, account_type: "customer"\|"owner", phone?}` → 201 `{access_token, user}` + refresh cookie | Password ≥ 10 chars, not all-numeric, not equal to email. 409 `EMAIL_TAKEN`. Rate limit 5/min/IP. |
| POST | `/auth/login` | — | `{email, password}` → 200 `{access_token, user}` + cookie | 401 `INVALID_CREDENTIALS` (same message for unknown email and wrong password). 403 if suspended. Rate limit 10/min/IP + 5 failures/15 min/email. |
| POST | `/auth/refresh` | cookie | — → 200 `{access_token, user}` + rotated cookie | Requires `X-Requested-With` header. 401 if missing/expired/revoked; reuse → revoke family. |
| POST | `/auth/logout` | cookie | — → 204 | Revokes session, clears cookie. |
| POST | `/auth/logout-all` | any | — → 204 | Revokes all sessions, bumps `token_version`. |
| POST | `/auth/forgot-password` | — | `{email}` → 202 | Always 202 (no account enumeration). Rate limit 3/15 min/email. |
| POST | `/auth/reset-password` | — | `{token, new_password}` → 204 | 400 `TOKEN_INVALID` (expired/used). Revokes all sessions. |
| POST | `/auth/verify-email` | — | `{token}` → 204 | |
| POST | `/auth/resend-verification` | any | — → 202 | Rate limited. |

## Resorts (public)
| Method | Path | Auth | Purpose |
|---|---|---|---|
| GET | `/resorts/search` | opt | Main search (params below) |
| GET | `/resorts/featured` | — | Landing page cards |
| GET | `/resorts/{slug}` | opt | Full details + active room types (only `published`; `is_favourite` when logged in) |
| GET | `/resorts/{id}/availability` | — | `?check_in&check_out&adults&children&rooms` → per room type: `{available_units, fits_occupancy, price: {...breakdown}}` |

| POST | `/resorts/{id}/enquiries` | opt | `{name, email, message}` — rate limited 3/hour/IP |

**`GET /resorts/search` query parameters**

| Param | Type | Notes |
|---|---|---|
| `q` | string ≤ 80 | destination, town, or resort name |
| `destination` | slug | exact destination |
| `state` | enum | |
| `check_in`, `check_out` | date | both or neither; check-out > check-in; check-in ≥ today (IST); max 30 nights |
| `adults` (1–20), `children` (0–10), `rooms` (1–5) | int | default 2/0/1 |
| `flexible` | int 0–3 | ± days window; returns cheapest available start date per resort |
| `min_price`, `max_price` | int (₹) | `price_basis=night\|total` (total requires dates) |
| `min_rating` | 3, 3.5, 4, 4.5 | |
| `property_type`, `category`, `amenity`, `surrounding` | repeated params | `?amenity=pool&amenity=wifi` (AND for amenities, OR within others) |
| `max_distance_km` | number | from destination centre (requires `destination`) |
| `available_only` | bool | default true when dates given |
| `sort` | enum | `recommended` (default), `price_asc`, `price_desc`, `rating`, `reviews` |
| `page`, `page_size` | int | |

Response item:
```json
{
  "id": "...", "slug": "misty-ridge-coorg", "name": "Misty Ridge Plantation Stay",
  "is_sample": true, "destination": {"name": "Coorg", "state": "karnataka"},
  "property_type": "cottage", "cover_image": {...}, "amenities": ["pool","wifi"],
  "rating": {"avg": 4.6, "count": 18},
  "price": {
    "kind": "starting",            // "starting" (no dates) or "stay" (dates given)
    "per_night_paise": 600000,
    "total_paise": null,           // set when kind = "stay"
    "taxes_included": false,
    "meal_plan": "breakfast"
  },
  "available": null                // true/false when dates are given
}
```
Response also includes `applied_filters` (echo, for the filter chips) and `facets` (counts per amenity/category for the current query, best-effort).

## Bookings — customer
| Method | Path | Auth | Body → Response | Notes / errors |
|---|---|---|---|---|
| POST | `/bookings/quote` | opt | `{room_type_id, check_in, check_out, rooms, adults, children, child_ages[], coupon_code?}` → `{available, price}` | No inventory change. 400 `INVALID_DATES`, `OCCUPANCY_EXCEEDED`; 409 `ROOM_UNAVAILABLE`. |
| POST | `/bookings` | C | same as quote + `{guest_details: {name, email, phone, age, nationality, arrival_time?}, special_requests?}`; header **`Idempotency-Key`** (UUID, required) → 201 booking (`pending_payment`, `hold_expires_at`) | Price recomputed server-side. Same key + same body → 200 with the original booking. Same key + different body → 409 `IDEMPOTENCY_KEY_REUSED`. 409 `ROOM_UNAVAILABLE`. 403 `EMAIL_NOT_VERIFIED`. 422 if `age < 18`, invalid phone, or child ages missing. |
| GET | `/bookings` | C | `?status=upcoming\|past\|cancelled` → page | |
| GET | `/bookings/{id}` | C | → booking + `cancellation_preview` | 404 if not the user's |
| POST | `/bookings/{id}/cancel` | C | `{reason?}` → booking | 400 `NOT_CANCELLABLE`. Releases inventory atomically. |

## Rate limits (per IP unless stated)

| Endpoint group | Limit |
|---|---|
| signup | 5/min |
| login | 10/min, plus 5 failed attempts per email per 15 min |
| forgot-password / resend-verification | 3 per 15 min per email |
| enquiries | 3/hour |
| booking create | 10/min per user |
| everything else | 120/min |
